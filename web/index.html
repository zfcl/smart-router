Decision model

Scale-invariant utility, not a price ceiling shortcut.

Each request gets its own expected input/output token mix. Reliability changes expected cost and expected completion time; tail jitter receives a separate penalty.

Lossᵢ = w₍c₎ ln(Cᵢ*/C̃) + w₍t₎ ln(Tᵢ*/T̃) + w₍s₎ ln(Jᵢ/J̃) + w₍r₎ ln(Riskᵢ/Risk̃)
Scoreᵢ = exp(−Lossᵢ)

C* and T* are reliability-adjusted. The log formulation makes the result invariant to units and produces diminishing returns: moving from 10→40 tok/s matters far more than 90→120 tok/s.
